# 【アプリ名（IT資格学習支援システム）】

ITパスポートおよび基本情報技術者試験の学習をサポートし、同時に「学習行動と記憶定着」に関する実証実験（Learning Analytics）を行うための卒業研究用Webアプリケーションです。

## :star2: 主な機能

* **資格試験対策クイズ**: ITパスポート・基本情報技術者試験の過去問データ（JSON）を用いたクイズ機能。
* **学習プロセスの制御**:
  * **初回確認テスト**: 学習初期の実力を測定する固定問題テスト（必須受験）。
  * **自由学習**: 忘却曲線や分野・出題形式に基づいた柔軟な問題の絞り込み。
  * **任意実力テスト**: 全体バランスを考慮した条件付きランダム抽出（Greedy方式）による実力テスト。
* **分散学習（SRS）とメタ認知**:
  * 解答時の「自信度」と「正誤」から**推定記憶保持率**を算出し、効率的な復習スケジュールを裏側で計算。
* **学習ダッシュボード**:
  * 推定記憶保持率の分布、高確信誤答（思い込み）の可視化など、メタ認知を促す分析グラフを提供。
* **自動リマインド機能（SES連携）**:
  * 推定保持率が40%以下に低下した問題や、高確信誤答の問題を検知し、毎朝8時にリマインドメールを自動送信。
* **研究データ抽出（分析スクリプト）**:
  * DynamoDBから学習ログを取得し、再回答のトランジション分析や、初期状態と自由学習の相関分析用CSVを一括出力。

## :tools: 使用技術

* **フロントエンド・バックエンド**: Python, Streamlit
* **データベース・インフラ**: AWS (DynamoDB, SES) / `boto3` による連携
* **データ処理・可視化**: Pandas, NumPy, Plotly
* **タスク自動化・CI/CD**: GitHub Actions (リマインドバッチの定期実行)
* **開発環境**: Dev Containers
* **その他**: LLM（AI）を利用した解説生成データ
